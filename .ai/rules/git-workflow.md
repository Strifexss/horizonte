# Git: apenas `master` e `feature`

- Existem só duas branches de trabalho: `master` e `feature`.
- Todo pedido novo, correção ou feature vai por padrão na branch `feature`. Não crie branch por tarefa (`cursor/...`, uma branch por pedido, etc.).
- Não faça merge nem push para `master` até o usuário pedir explicitamente para consolidar/subir.
- Commits e push no dia a dia ficam em `feature`.
- Não apague `master` nem `feature`. Branches temporárias antigas podem ser removidas se o usuário pedir limpeza.
